Omugwo Academy – Finance Tracking Application (Expanded Concept)
1. Purpose & Goal

Create a simple but robust finance tracking application for Omugwo Academy that helps the organization clearly understand its financial health at any point in time.
The app should record all income and expenses, automatically compute profit or loss, and present clear financial reports that support decision-making, accountability, and planning.

The core objective is visibility:

Where money is coming from

Where money is going

Whether the academy is operating at a profit or a loss

Trends over time (monthly, quarterly, yearly)

2. Core Features
A. Income Management

The app should allow users to record and manage all sources of income.

Income Categories (configurable):

Course purchases / program fees

Donations

Sponsorships / grants

Events / workshops

Merchandise (if applicable)

Other income (custom)

Income Fields:

Amount

Date received

Category

Payment method (cash, transfer, card, online)

Payer / source (optional)

Reference / description

Attachment (receipt, transfer screenshot, invoice – optional)

B. Expense Management

The app should track all operational and administrative expenses.

Expense Categories (configurable):

Staff salaries / facilitators’ fees

Content production (video, editing, design)

Marketing & advertising

Technology & software subscriptions

Office / operational costs

Utilities (internet, power, hosting)

Training & development

Logistics & events

Miscellaneous expenses

Expense Fields:

Amount

Date incurred

Category

Payment method

Vendor / payee

Description / notes

Attachment (receipt, invoice)

3. Profit & Loss Computation

The system should automatically:

Calculate total income for a selected period

Calculate total expenses for the same period

Compute net profit or loss

Display results clearly (e.g., Profit = green, Loss = red)

This should work for:

Daily

Monthly

Quarterly

Yearly views

4. Financial Reports & Dashboards
A. Financial Overview Dashboard

A high-level snapshot showing:

Total income

Total expenses

Net profit or loss

Cash flow trend

Top income categories

Top expense categories

B. Detailed Reports

Income report by category

Expense report by category

Profit & loss statement

Period comparison (e.g., this month vs last month)

C. Filters

Date range

Category

Payment method

5. Categories & Customization

Admin users should be able to create, edit, or deactivate categories

Categories should be reusable across reports

Support tagging transactions (e.g., “2026 cohort”, “Scholarship program”)

6. Users & Access Control (Optional but Recommended)

Admin: full access

Finance/Admin staff: create & edit transactions

View-only users: reports only

7. Data Export & Records

Export reports to CSV / Excel / PDF

Maintain a historical audit trail

Prevent accidental deletion (soft delete / archive)

8. Non-Functional Requirements

Simple and intuitive UI (non-accountants can use it)

Mobile-friendly

Secure access and data storage

Accurate calculations and validations

9. Future Enhancements (Optional Roadmap)

Budgeting and budget vs actual analysis

Automated reminders for recurring expenses

Integration with bank statements

Multi-branch or multi-project tracking

Basic forecasting based on past data
